# SIRM - Sistem Informasi Rekam Medis (PHP 8.1+ & MySQL)

2. Import database/sirm.sql lewat phpMyAdmin
3. Sesuaikan config/config.php
4. Buka /install.php sekali, lalu HAPUS file tersebut
